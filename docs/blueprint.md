# **App Name**: Health Heaven

## Core Features:

- Secured Login: Secure user authentication using NextAuth.js with email/password and potentially social providers.
- Landing Page: A visually appealing and informative landing page with sections for introduction, features, and call-to-action.
- User Profile: User profile page accessible after login to manage account details.
- Item Assessment: Separate page for adding item assessment with a responsive search bar with drop-down menu suggestions fetched from MongoDB in real-time, then generates a summary after ingredients are fetched by MongoDB, then a custom prompt is sent to Gemini to assist. This feature will use the LLM as a tool to incorporate information into the output.

## Style Guidelines:

- Primary color: Dark blue (#1A237E) for trust and security.
- Secondary color: Light gray (#EEEEEE) for backgrounds and subtle elements.
- Accent: Teal (#00BCD4) for highlights, buttons, and interactive elements.
- Clean and modern layout with a focus on readability and user experience.
- Clear and professional typography for readability.
- Use a set of consistent icons throughout the application.
